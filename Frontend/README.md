# Frontend

Aplicación Angular con Angular Material para el sistema de gestión de caja y turnos.

> Estado: en desarrollo.

## Lineamientos

- Desarrollo modularizado, con rutas que cargan los módulos por lazy loading.
- Protección de rutas con guards según el rol.
- Interceptor HTTP que adjunta el JWT en todas las peticiones.
- Menú cargado desde la base de datos de acuerdo al rol.

Las instrucciones de ejecución se documentan aquí al completarse.
