# Uso de IA en el desarrollo

Esta carpeta registra los prompts y skills utilizados con agentes de IA, tal como lo solicita la prueba.

## Herramienta

- **Agente:** Claude Code (extensión de VS Code), de Anthropic.
- **Skills:** no se usaron skills personalizados; solo las herramientas integradas del agente (lectura y edición de archivos, terminal).

## Forma de trabajo

1. Se compartió con el agente el enunciado de la prueba.
2. Se definió en conjunto el stack y la arquitectura antes de escribir código.
3. El desarrollo avanza por etapas, con revisión del autor en cada una.

## Archivos

- [prompts.md](prompts.md): registro cronológico de los prompts enviados al agente.
